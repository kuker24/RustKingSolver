# Kata depan

## Aturan inti

**Kata depan `di`, `ke`, dan `dari` ditulis terpisah dari kata yang mengikutinya.**

| Benar | Salah | Catatan |
|-------|-------|---------|
| di kantor | dikantor | kata depan tempat |
| ke sekolah | kesekolah | |
| dari rumah | darirumah | |
| di dalam | didalam | |
| ke luar kota | keluar kota (makna berbeda) | *keluar* = verba; *ke luar* = kata depan + *luar* |

## Bedakan dengan imbuhan `di-` (pasif)

| Bentuk | Jenis | Contoh |
|--------|-------|--------|
| ditulis | imbuhan pasif `di-` | Naskah itu **ditulis** ulang. |
| di tulis (salah jika maksud pasif) | — | jangan pisah imbuhan |
| di meja | kata depan | Buku ada **di meja**. |

Heuristik agent: jika setelah `di` langsung verba dasar yang membentuk pasif umum (`buat`, `tulis`, `baca`, `lihat`, …) → kemungkinan imbuhan; jika nominal tempat/arah → kata depan terpisah. Ambigu → `[PERLU_CEK_MANUSIA]`.
