# Gelar

Gabungan aturan kapital + singkatan.

Sumber utama:

- https://ejaan.kemendikdasmen.go.id/eyd/penggunaan-huruf/huruf-kapital/
- https://ejaan.kemendikdasmen.go.id/eyd/penulisan-kata/singkatan/

| Pola | Contoh benar |
|------|--------------|
| Gelar + nama | Doktor Ir. Soekarno; Prof. Dr. … |
| Nama + gelar akademik | Ani Wijaya, S.Kom., M.T. |
| Singkatan gelar | S.E.; M.Si.; Dr. (cek daftar EYD) |

Hindari: `DR.` all-caps nonstandar; `S.Kom` tanpa titik jika pedoman kampus mengikuti EYD bertitik. Beberapa kampus punya *template* sendiri — utamakan template lembaga, catat di laporan jika bentrok EYD. `[PERLU_CEK_MANUSIA]`
