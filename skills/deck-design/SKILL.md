# deck-design

Consulting slide specialist. One slide = one message. Titles carry the conclusion.

Intent: `slides_pptx`. Generating or mechanically checking decks lives here.
`smartdoc` = PDF/DOCX contracts. `markitdown` = ingest existing PPTX to Markdown.
Impeccable `email.md` = HTML email. `diagram-design` = editorial SVG, not slides.

## When

- User asks for consulting slides, board deck, PPTX, 16:9 HTML sections, or a slide-rules check.
- A storyline of titles must be written before layout.

## When not

- Per-job document intelligence, OCR, letters, forms → `smartdoc`.
- Convert existing PPTX to Markdown → `markitdown`.
- Product UI / marketing site → `found-this-design` / `impeccable`.
- Do not vendor upstream 62-type HTML/PPTX template packs into this overlay.

## Load

- Rules: [references/rules.md](references/rules.md)
- Attribution: [NOTICE.md](NOTICE.md)

## Pipeline

1. Lock purpose, audience, IN/OUT (3–5 lines).
2. Write a **title storyline** (one concluding title per slide). Titles alone must read as a story.
3. Pick a showing (table with axes, chart, two-column fact/implication, metric cards). Do not dump charts into tables.
4. Draft 16:9 HTML (`1 section = 1 slide`) using project or first-party CSS tokens. No rounded-rect decoration kit. No POINT footer band.
5. Mechanical check against [references/rules.md](references/rules.md). FAIL must be 0 before ship (cover/back-cover empty-title WARN allowed).
6. Human pass: overlapping, overflow, empty lower half, hyphenation, left/right baseline mismatch.
7. PPTX export is optional. Prefer PDF/HTML. If `python-pptx` (or an equivalent the **project** already has) is missing, export is `NOT_CONFIGURED` — do not pip-install into the overlay.

Missing Chromium for print-to-PDF is `NOT_CONFIGURED`, not PASS. Never Google Chrome as a required binary; headless Chromium if the host already has it.

## Hard rules

- Do not copy `assets/SuperTemplate_62type.pptx` or upstream parts HTML into the overlay.
- Do not put “generated by …” on every slide; one source line on the back cover is enough.
- Numbers in the title must match body counts.
- SmartDoc must not generate PPTX.
